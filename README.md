# AdventOfCode
Códigos realizados --> 1,5,7,11,16

Dejar claro que todos los código han sido compilados y revisado en la terminal de un mac y se ha utilizado "g++ -std=c++20 -0 programa program.cpp". Esto es debido a que si no se generaban errores a la hora de compilarlo debido a que el compilador era más antigua y no reconocía cierta sintaxis que no debería generar problemas en otros compiladores. Se entiende que aun así, todos los códigos deberían compilar en cualquier terminal de Linux usando los comandos puestos en los readme de los programas.
